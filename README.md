# 超星学习通缺勤人员统计

自动统计超星学习通签到表中"未参与"的学生姓名，并生成缺勤汇总报告。

## 功能特性

- 自动扫描指定文件夹中的所有Excel签到文件
- 统计每次签到中"未参与"的学生
- 生成缺勤次数汇总统计
- 输出格式化的Excel报告，包含三个工作表：
  - **缺勤次数统计**：按缺勤次数排序的学生名单
  - **各次缺勤名单**：每次签到的缺勤学生明细
  - **签到概览**：各次签到的整体情况

## 使用方法

1. 将超星学习通导出的签到Excel文件放入指定文件夹
2. 修改脚本中的 `SOURCE_DIR` 变量为你的文件夹名称
3. 运行脚本：

```bash
python 统计缺勤.py
```

## 依赖安装

```bash
pip install openpyxl
```

## 自定义配置

修改脚本顶部的配置项：

```python
SOURCE_DIR = Path("你的文件夹名称")      # 签到Excel文件所在文件夹
OUTPUT_FILE = Path("缺勤统计结果.xlsx")  # 输出文件名
ABSENT_STATUS = "未参与"                 # 缺勤状态标识
```

## Excel文件格式要求

- 文件格式：`.xlsx`
- 必须包含列：`姓名`、`学号/工号`、`行政班级`、`签到状态`
- 签到状态值为"未参与"的学生将被统计
